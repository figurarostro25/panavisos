# Dirección de marca PanAvisos

## Nombre público inicial

**PanAvisos**

Es directo, local y fácil de entender para clasificados, propiedades, empleos, servicios y marketplace. Como la marca aún se está construyendo, conviene que el sitio se sienta útil, cercano y en crecimiento.

Más adelante puede crearse una segunda marca premium conectada al mismo inventario, cuando PanAvisos ya tenga movimiento real.

## Sistema visual

- Tinta principal: `#17212B`
- Azul profundo: `#12313F`
- Verde azulado: `#1F6F78`
- Dorado CTA: `#D7B45A`
- Fondo suave: `#EEF3F6`
- Tipografía recomendada: sans serif robusta, legible y de peso alto
- Símbolo actual: monograma de anuncio dentro de una ficha cuadrada redondeada, con acento dorado
